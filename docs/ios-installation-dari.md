# نصب آزمایشی Al Furqan روی آیفون شخصی

نسخهٔ ۰.۱.۱، شمارهٔ ساخت ۲، برای iOS 16.4 و بالاتر آماده شده است. نمای صفحه‌ای قرآن، ترجمه‌ها و ابزارهای مطالعه در آن موجود است. متن قرآن، فونت‌ها، تلاوت و ترجمه به انترنت نیاز دارند.

این بسته، فایل نصب مستقیم آیفون نیست. دو فایل ZIP داخل آن برای شبیه‌ساز Mac و آرشیف بدون امضای آیفون است. برای نصب اپ مستقل روی گوشی شخصی، امضای حساب واقعی Apple شما در Xcode لازم می‌شود.

## راه سادهٔ فعلی برای استفاده از سایت

۱. در آیفون، getfurqan.online را با Safari باز کنید.
۲. Share را بزنید و Add to Home Screen را انتخاب کنید.
۳. اگر Open as Web App نمایش داده شد، فعالش کنید و Add را بزنید.

QR آیفون در پایین سایت همین راهنما را باز می‌کند.

## نصب اپ مستقل با Mac و Xcode

۱. در Mac، Xcode 26 یا جدیدتر و Node 22 یا جدیدتر را آماده کنید.
۲. سورس پروژه را از https://github.com/mirkhel1380/getfurqan.online بگیرید.
۳. در Terminal، وارد پوشهٔ mobile شوید و اجرا کنید:

```sh
npm ci
npm run build
npm run check
npx cap sync ios
npx cap open ios
```

۴. در Xcode، بخش Settings → Accounts را باز کنید و حساب Apple خود را همان‌جا وارد کنید.
۵. پروژهٔ App و سپس Signing & Capabilities را انتخاب کنید. Automatically manage signing را فعال و Team واقعی خود را انتخاب کنید.
۶. آیفون را وصل کنید، مراحل Trust و Developer Mode را روی خود گوشی تکمیل کنید، گوشی را به‌عنوان مقصد انتخاب کرده و Run را بزنید.

شناسهٔ توسعهٔ پروژه online.getfurqan.app است. Xcode باید آن را برای Team شما بپذیرد؛ اگر در دسترس نبود، شناسهٔ دیگری در دامنهٔ خودتان باید در پروژه و capacitor.config.json یکسان تنظیم شود.

Apple ID عادی با Personal Team برای تست محدود روی گوشی شخصی قابل استفاده است. پروفایل این روش پس از ۷ روز منقضی می‌شود و اپ باید دوباره از Xcode نصب شود. این روش، توزیع عمومی برای همهٔ بازدیدکنندگان سایت نیست.

## آزمایش روی گوشی

سه رسم‌الخط قرآن، شماره‌های آیات، ترجمه و تفسیر، پخش تلاوت، زبان دری، تم روشن و تاریک، ذخیرهٔ آیات و بازگشت به جای مطالعه را بررسی کنید. در نسخهٔ فعلی، مطالعه به‌صورت مهمان است و ذخیره‌ها در خود دستگاه می‌مانند. تست ساخت و بررسی فایل‌ها، جای بازبینی متن قرآن توسط شخص متخصص یا آزمایش روی آیفون واقعی را نمی‌گیرد.

راهنمای رسمی Apple: https://developer.apple.com/help/account/basics/about-your-developer-account
